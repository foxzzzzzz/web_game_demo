## 1. 测试约定

- 规则测试使用固定时钟和固定随机源，避免依赖真实等待和随机波动。
- 数值期望来自外部配置；测试引用配置 ID，不复制业务常量。
- 每个用例必须能映射到 PRD 需求和对应 Phase。
- E2E 使用测试驱动入口快速发放经验/生成敌人，但该入口只在测试构建可用。
